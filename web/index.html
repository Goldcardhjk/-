常见问题

数据存在哪？会不会泄露？

关系数据存在本机数据库，一个账号一个独立库，不上传、不联网。只有你主动使用大模型能力时，才会把必要的文本发给你配置的模型服务。

积分是干什么用的？

积分只用于真实大模型 API 调用（关系判断、祝福语生成等）。本地检索、模板和界面功能不扣积分——不烧模型算力的地方，我们不收费。

能在几台电脑上用？

桌面版按账号本地建库，换机器时可以用「备份与恢复」把整库带走；密钥与支付配置不进备份。
